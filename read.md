# Sigmatic Data Profiling & Quality App

A reusable Databricks application for profiling Unity Catalog tables and assessing data quality.

## Features

- Table profiling
- Null analysis
- Duplicate detection
- Schema analysis
- Quality scoring
- PII detection
- Report export

## Tech Stack

- Databricks Asset Bundles
- Databricks Apps (Streamlit)
- Unity Catalog
- Python
- PySpark
